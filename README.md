# SynMatch

This repo is the PyTorch implementation for the paper:

**["SynMatch: Rethinking Consistency in Medical Image Segmentation with Sparse Annotations"](https://)** 

## Usage

### 0. Requirements
The code was developed using Python 3.8 with PyTorch 1.11.0.
All experiments in our paper were conducted on a single NVIDIA A40 GPU with 48G GPU memory.

Install the main packages:
```angular2html
pytorch == 1.11.0
torchvision == 0.12.0
```

### 1. Data Preparation
#### 1.1. Download data
The dataset can be downloaded from the following links:
* ACDC Dataset - [Link](https://www.creatis.insa-lyon.fr/Challenge/acdc/) 
* ISIC Dataset - [Link](https://challenge.isic-archive.com/data/#2018)
* Kvasir-SEG Dataset - [Link](https://datasets.simula.no/kvasir-seg/)

PS: *Please cite the original dataset papers when using the data in your publications.*

#### 1.2. Scribble Annotations
The scribble annotations for _ACDC_ are provided by Gabriele Valvano, Andrea Leo, Sotirios A. Tsaftaris - [Link](https://vios-s.github.io/multiscale-adversarial-attention-gates/data).

For the _ISIC_ and _Kvasir-SEG_ datasets, users may either directly use the provided scribble annotations (within the `data` folders and generated by `mask2scribble.py`) or regenerate scribble annotations using `mask2scribble.py`.

_PS: We highly encourage future efforts toward providing higher-quality scribble annotations._


#### 1.3. Split Dataset
Follow the list files (within the `data` folders) to split the datasets

### 2. Training
```angular2html
python train_synmatch.py
```

### 3. Evaluation
```angular2html
python eval.py
```
